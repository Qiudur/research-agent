## English

A project-wide code license has not yet been selected. Public access to the repository does not itself add a general license grant. This page records the current status; it is not a license.

### Data

- The 18 tabular dataset source records in `tasks/tab-*/SOURCE.md` declare **[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)** and retain dataset attribution and transformation notes. Each dataset remains subject to its own documented terms; these data licenses do not license the project’s code.
- The ETF snapshot’s Kaggle uploader declares **CC0**. The source data’s rights and redistribution terms are separate from the project’s code license; Yahoo Finance rights and redistribution permission have not been independently verified. Raw and normalized market CSV files remain local and are not redistributed with the quant case. See [data sources and rights](docs/etf-data-sources.md).

### Dependencies

Third-party dependencies remain subject to their own licenses. The dependency declarations in [pyproject.toml](pyproject.toml) and [requirements-tabular.txt](requirements-tabular.txt) do not replace those terms or determine this project’s code license.
