## 质量门槛

预设规则：最多 2 题均分低于基线超过 0.1，且 speedup 与 tabular 各自的题目均分中位数下降不超过 0.1。

- 超过单题容差的有 3 题：spd-rolling-mean, tab-phishing-websites, tab-german-credit，超过允许的 2 题。
- speedup 中位数：0.996 → 0.966；tabular 中位数：0.303 → 0.535。两场景中位数子条件均满足，但总门槛失败。
- tab-phishing-websites 的大幅负分主导总体均值；不能只用总体均分或非负分数/token 排名宣布候选获胜。

因此本轮到此封存；若未来要继续优化，须在新一轮 practice 研究中另建候选，不改写本次结果，也不将失败策略送入正式评估。
