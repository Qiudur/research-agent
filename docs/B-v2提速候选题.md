# bank-v2 新提速考试候选题

这五题均未出现在 `bank-v1`，只新增候选任务包与 `harness_worker.py` 的 workload 类型；本分支不改冻结题库、一次性标记或正式批次。所有检查都使用 macOS 沙箱的 **dev** split；没有读取或运行 holdout。保留四题的探索性固定种子测量、源码 SHA 和环境见 `B-v2提速候选dev校准.json`；止损题的独占 dev 测量将单列为 `B-v2提速stop-loss-dev校准.json`。最终冻结仍需在合入后的同一代码版本上把五题全部重测。

| 任务 | 瓶颈与参考方向 | dev 大小 | 原始中位 raw | 参考中位 raw |
|---|---|---:|---:|---:|
| `spd-pair-sum-count` | 二重配对循环 → 流式计数表 | 2,600 | 1.0076 | 391.3197 |
| `spd-range-counts` | 逐查询扫描 → 排序后二分 | 3,200 | 0.9927 | 134.6891 |
| `spd-builtin-sort` | 原始方案已调用内建排序；`stop_loss` | 30,000 | 1.0043 | 1.0247 |
| `spd-running-median` | 每个前缀重排 → 双堆 | 1,600 | 1.0007 | 98.1291 |
| `spd-inversion-count` | 二重逆序计数 → Fenwick 树 | 2,700 | 1.0024 | 52.2060 |

`spd-builtin-sort` 在任务类型预审时替换了 `spd-sliding-minimum`，替换依据是每场景考试集必须有真正的 `stop_loss`，不是根据模型或 holdout 成绩筛选。新题输入为超过固定宽度整数范围的任意精度有符号整数，原始方案和参考方案都使用 Python 内建 `sorted`。两份源码 SHA 完全一致；三个固定 dev 种子的参考减原始 raw 差有正有负，中位数约 +0.0205，不构成可靠算法增益。评分额外检查输入保持不变，阻止原地排序通过语义校验。新 `already_optimized_builtin` 止损 trigger 准确描述内建排序；测量与 SHA 见 `B-v2提速stop-loss-dev校准.json`。

探索性测量固定种子 `20261114`、`20261115`、`20261116`，每题分别用原始方案和参考方案在 dev 沙箱评分，表中取 raw ratio 中位数。该比率仅验证题目可测，不是代理模型成绩。入 bank-v2 之前还需要在最终集成提交上重新做五题 dev 测量、朴素成本多次校准、按冻结规则分难度、确认表格题与版本化考试题单，再冻结源文件及协议；不得拿此候选集冒充已完成的 bank-v1 正式考试。
