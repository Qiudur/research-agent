## 尚待外部输入与正式验收

1. 用户已明确比赛没有指定模型或题目预算；本项目先以自选 Qwen 模型及 token 预算验证规划能力。若要报告现金成本，仍需核实网关四桶实际计价和币种；保持凭据不入库。
2. 朴素配置已在两道练习题各运行一次；仍需更多配对重复、覆盖全部练习题，按同一资源单位测稳定的 naive_cost 并据此定 difficulty；核对所有 24 题任务包、来源许可和 dev 校准，然后冻结 bank-v1 与代码提交。
3. 真实模型自动自研究已在两道 practice 题完成一次 dev 试验，候选未胜默认版；继续只在练习题上改进与复评，再用正式准备好的 bank 对 selection.config_path 和 SHA 做一次准入。
4. 正式验证集只做一次三遍配对准入；通过后，冻结代码、库和配置，再在考试集上执行四线各三遍的唯一正式轮次。
5. 用审计报告生成真实分数、花费、回本点和演示资料；若准入失败或考试不显著，直接报告无明确优势。正式录屏、答辩稿中的数字均要引用实际账本。

正式运行前可执行 scripts/preflight.py 或 evaluation.cli preflight；两者只读并逐项列出阻碍。当前不能把 B/C 工程机制已完成等同于正式实验已完成。
