# bank-v2 恢复试验预注册（草案，未运行）

更新：2026-11-14。bank-v1 的唯一正式考试在一次 holdout 评分无分数后中止；其 attempt 标记和 86 道已完成题的账本保持原样，**不得补跑或把部分成绩写成完整成绩**。本文件在任何 bank-v2 模型评分前明确恢复试验的条件。bank-v2 是新的后续试验，不是 bank-v1 的重考或原结论的修补。

## 入场条件

1. 新考试必须有 10 道未进入 bank-v1 的题：提速、表格各 5 道。题目来源、许可、正确性、dev 参考基线和 ceiling、隐藏 split 隔离须在第一次 holdout 前逐题复核；表格参考 AUC gap 至少 0.01，避免接近零的归一化分母。不得依据 bank-v1 考试结果挑选对某配置有利的题。若不足 10 道合格题，不启动正式 bank-v2。
2. 保留 bank-v1 的 10 道 practice 和 4 道 validation 作为重复训练/门槛题；它们不构成新的独立验证。研究候选仍为已选的 auto-02，其配置和四角色提示词不基于 bank-v1 validation/exam 改动。只有新考试的 10 道题可支持新的独立考试对比。
3. 新版 B 必须先在纯夹具和 dev 上确认：候选 sandbox 子进程超时、OOM 或异常按 0 分记录一次，不重试，并保存安全的错误类别；可信原始方案、主机评分器或无效协议发生错误则中止。此规则对 dev/holdout 一致，并在正式代码提交冻结前写入测试。bank-v1 结果不按新规则回填。
4. 使用独立工作区和全新 `bank-v2` 一次性标记；冻结题库、代码提交、配置及提示词、价目表、数据与评分输入 SHA。预检和全部本地回归通过后才能打开考试。

## 固定实验口径

- 可本地部署的 `qwen3.5-27b` 经授权网关调用；内部 `TOKENS` 四桶计量，四桶费率均为 1；单题自选 40,000 token，上限每次输出 2,048 token，请求前预留 12,000 token。不是现金价格或官方比赛成绩。
- 与原协议一致：naive、default、default_lib、tuned_lib 四线各三遍 practice；default_lib 与 tuned_lib 各三遍 validation；研究版仅在三遍分数均不降且平均 token 更低时进入考试，否则考试仅 naive/default/default_lib 三线各三遍。`workers=8`，所有 sandbox 执行和评分串行。
- 失败的模型调用仍计入 token 成本。考试只用每题首次 holdout 尝试；对因基础设施失败而中止的批次，不补跑同一题库版本。报告同时列出失败、预算、总用量、逐遍分数与四桶；未完成时不报告完整三线比较或回本点。

## 退出条件

在题目来源、许可、dev 参考 gap、候选失败计分与独立审计任何一项未就绪时，停止 bank-v2 正式实验，仅交付 bank-v1 的可审计部分结果和明确限制。新题和代码尚在并行准备，本文件不宣称 bank-v2 已启动或完成。
