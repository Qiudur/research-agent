# 现场演示与答辩提纲

本文件是演示提纲，不是成绩报告。截至 2026-11-14，bank-v1 已完成真实模型的 dev 朴素成本校准并冻结；v2 练习自研究、一次性验证和考试的结果仍待各自真实账本填入，当前没有可展示的三线或四线考试结论。内部研究选用可本地部署的 qwen3.5-27b，经授权网关调用；每题自选 40,000 token 预算，价格表以四桶 token 等权计量（`currency=TOKENS`、`test_only=false`）。这不是本机部署、现金价格或官方比赛成绩。比赛最终模型、现金价格和题目预算未给定，不得把 TEST-only 联调图、脚本角色结果或 dev 试点剪成考试效果。

## 内部研究证据入口

1. v2 练习自研究完成后，先核对 `auto_self_research_report.json` 的候选选择、全部提案及练习成本，并验证选中配置和四角色提示词的 SHA256；`selection=null` 时停在练习阶段，不启动一次性验证或考试。
2. 只有批次和真实账本完整后，才使用 `evaluation.cli figures` 并传入 `--auto-study-dir`，生成 HTML 与同名 JSON。出图过程复核批次封存源、六份配对验证、九或十二份考试报告、自研究全部成本、选中配置哈希和研究版 manifest。
3. 打开生成的 JSON，确认 `phase=exam`、`test_only=false`、`currency=TOKENS`。`test_only=false` 只表示本项目内部正式协议，不表示官方比赛成绩或现金定价。若 `admission.claim=admitted`，展示四条线；若为 `rejected`，只展示三条考试线并说明研究版未入场。每条线恰有三遍运行。把 `comparisons.*.claim` 原样写入答辩稿；`no_clear_difference` 就写“未看出明确差别”。
4. 只有 `breakeven.eligible=true` 且 `breakeven.tasks` 有值时，才报告以 token 计的研究成本回收题数，不能称为现金回本。逐题 token、得分和耗时在 `task_rows` 中，每行的 `run_id`、`task_id`、`task_end_seq` 可定位到对应账本。

## 两分钟讲述顺序

- **问题**：给同一个可本地部署模型研究任务，在自选 token 预算内规划实验，检验效果、资源消耗和耗时；模型实际经授权网关调用。
- **方法**：代码规则调度实验树和预算；规划、执行、诊断、总结按角色分档；B 沙箱独立检验正确性、速度或 AUC；C 按网关返回的四桶 token 记账。
- **学习**：练习题累积有证据的能力库，自动自研究只用练习题搜索配置和提示词；验证题的三遍配对准入决定研究版能否进入考试，考试库冻结。
- **结果**：考试账本完整并审计通过后，展示生成的 HTML 中三或四线的三遍范围、逐题走势和账本引用；按同名 JSON 原样解释分数差异、波动、token 消耗及适用时的回收题数。若尚无完整考试账本或没有明确优势，直接说明。
- **防作弊**：展示 Bank Marketing 的 `duration` 禁用规则和推断缺列、提速止损题，以及仅 C 能触发的一次性 holdout 门禁；不要展示考试隐藏数据。

## 分屏与录屏

内部研究的考试结束后，从已完成的报告中选同一提速任务的空库和练过库运行，记录两个 run ID 及其 `task_end_seq`，再运行：

    .venv/bin/python -m dashboard.serve --run-dir runs/<空库run_id> --other-run-dir runs/<练过库run_id> --port 8765

浏览器打开本机服务地址。左侧空库，右侧练过库；每秒刷新一次。现场若重新运行任务，只能标为演示，不能写回考试报告。录屏前确认画面与解说均未露出 API Key、隐藏标签、候选源码中的私人路径；录屏文件和运行目录留在本机，不提交到 Git。

## 待真实账本后补入

- v2 自研究的 study/run ID、候选选择及配置与提示词 SHA256、提案和练习总 token；未完成前全部留空。
- 一次性验证的六份报告、配对分数与 token、准入结论；考试的九或十二份报告、三项比较的 `claim`、平均分差和三遍范围。
- 模型名、`TOKENS` 价格表 SHA256、题库版本、代码提交 SHA；各配置平均 token、可报告时的回收题数、逐题预算违例及失败记录。
- 同一任务的左右分屏 run ID、考试报告中的证据定位和录屏文件名。

这些字段只能从对应阶段的真实账本和自动审计报告摘录；不能用 TEST 联调、dev 试点或校准数据代填。若将来获得比赛的官方模型、预算和现金价目，应另建并审计相应研究，不能把本次 TOKENS 账本换算成官方成绩。
